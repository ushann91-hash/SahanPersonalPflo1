# Sahan Mackenzie — Personal Portfolio

This is the local, front-end-first foundation for Sahan Mackenzie's personal portfolio. It is deliberately separate from the existing business website and ready to transfer into a fresh Lovable project once the direction is approved.

## What is included

- A responsive five-page editorial portfolio shell
- A documented content plan and asset checklist
- A Lovable build prompt for recreating the approved direction
- A restrained temporary wordmark and a place for an original monogram concept
