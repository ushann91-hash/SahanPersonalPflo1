# Project Skills Library

These project-local skills hold the standard for Sahan Mackenzie’s personal portfolio. They are deliberately stored with the website so a future Lovable project, GitHub repository or collaborator receives the same direction.

| Skill | Use it for |
|---|---|
| `ui-ux-design` | Page structure, responsive behaviour, interaction and accessibility |
| `editorial-content` | Website copy, Journal articles and information pages |
| `portfolio-case-studies` | Curation, permissions, credits and project stories |
| `brand-assets` | Wordmark, monogram, image direction and asset hand-off |
| `frontend-quality` | Build review, SEO, performance and launch checks |

These are working standards, not publishing approval. The approved founder facts, client permissions and image licences remain the source of truth.
