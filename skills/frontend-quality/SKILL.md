# Front-end Quality

Keep components reusable and content editable. Do not connect an inbox, analytics, external account, GitHub repository, Lovable project or hosting provider without explicit instruction.

Before launch, verify:

- Mobile and desktop layouts; keyboard navigation and focus; reduced motion; contrast and semantic structure.
- Page title, meta description, canonical URL, social sharing image and sensible alt text.
- Responsive image sizing, compression, lazy loading where appropriate and no unnecessary heavy effects.
- Enquiry form labels, validation, error state, confirmation state, privacy copy and an approved destination.
- Factual copy, client permissions, photographer credits and no placeholder content left visible.
- Ownership of the Lovable workspace, GitHub repository, domain and deployment is clear and controlled by Sahan or an agreed owner.

Report issues in priority order and distinguish launch blockers from refinements.
