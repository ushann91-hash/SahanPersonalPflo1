# UI / UX Design

Create a calm, editorial experience for Sahan Mackenzie’s personal portfolio. Visitors should grasp Sahan’s point of view, see relevant work and find a clear next step without navigating a generic agency site.

- Preserve the launch structure: Home, Selected Work, Project Detail, Profile, Services and Start a Conversation.
- Use one clear action per section. Keep navigation short and the enquiry action visible.
- Build mobile-first. Test a narrow phone, tablet and large desktop; do not hide essential information behind hover.
- Use quiet animation only; respect reduced-motion settings and never use scroll hijacking.
- Maintain semantic headings, keyboard access, focus styles, legible contrast and meaningful image alt text.
- Prefer typography, space and real project imagery over decorative effects.

Before delivery, state the page goal, visitor action, content still needed and responsive/accessibility considerations.
